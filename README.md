# STUDY BUDDY
PW #2 MARQUEZ_DUROY_MORGA_COSTO
## Project descrption:
Study Buddy is an individualized platform designed specifically for students. In one app, you can take note of deadlines, grades, comply tasks, and create quizzess. All in one app!

## Features:
-	One-tap task creation
-	Smart categorization by subject/project 
- Built in quiz engine, generating questions from JSON
- Built in Grade Calculator

## How to run program:
1. Make sure you have FLASK downloaded in your terminal
2. Download the folder StudyBuddy.zip and unzip the folder.
3. Open the command prompt
4. Run the program by copy pasting the given link
